## Independent assessment

Freeze acceptance facts and executable counterexamples before model turns. Keep
rubric/tests outside each model's allowed directories. Check actual references
and tool logs for leakage. Isolation is separate copies and prompt scope, not an
OS-enforced hostile-agent sandbox. No previous reports or Git history in fixtures.

Score facts, not phrasing or agreement with a supplied label. Per fact: found
with supporting reference, partial, missed. A dangerous false negative is omission
of a mandatory risk/control or advice to implement in spite of that unresolved
risk. Report denominators and unsupported claims. No automatic keyword scoring.
Facts derive from original diffs and executable behavior, not another LLM's opinion.

Record total/cached/uncached input, output, actual tool calls, duration, no-input
interventions and any scope violations. Keep all runs, including incomplete ones.
One run/cell cannot establish statistical superiority. No quota-delta savings.
The previous 6-call run's added uncached tokens/cache changes and larger schema
resource explain candidates for overhead; do not retune this benchmark to green.
